## Configure name and email

´´´bash
git config --global --edit
´´´
1. navigate to name and email
2. click i to enter insert mode
3. remove # (comment) sign
4. put in your name and email
5. esc --> normal mode
6. :wq --> : = command-mode w = write q = quit
